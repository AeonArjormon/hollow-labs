# Shadow Jump 玩法优化计划

## 目标

把当前原型重新梳理为“双系统切换”的横版动作小游戏。

核心不是“切换一次，同时换场景和人物”，而是两个独立系统：

- **场景切换**：光场景 / 影场景，改变地图、平台、陷阱、机关、敌人分布。
- **形态切换**：光形态 / 影形态，改变角色外观、移动能力、攻击方式、特殊技能。

也就是说，人物无论处于光场景还是影场景，都可以自由切换光形态或影形态。

## 核心设计

游戏应该同时维护两个状态：

```text
sceneMode = light / shadow
formMode  = light / shadow
```

这两个状态互相独立，组合后形成 4 种玩法状态：

| 当前组合 | 场景表现 | 人物形态 | 玩法重点 |
| --- | --- | --- | --- |
| 光场景 + 光形态 | 天堂、云桥、圣光平台 | 天使 | 稳定状态，适合跳跃、远程、安全探索 |
| 光场景 + 影形态 | 天堂场景仍存在 | 地狱 | 反向组合，限时爆发，用近战处理光场景障碍 |
| 影场景 + 光形态 | 深渊、熔岩、裂隙平台 | 天使 | 反向组合，限时保命，用缓降和远程穿越危险区 |
| 影场景 + 影形态 | 深渊场景仍存在 | 地狱 | 稳定状态，适合高速、冲刺、近战爆发 |

设计原则：

- 场景决定“世界现在是什么样”。
- 形态决定“角色现在怎么操作”。
- 同属性组合是稳定状态，可以长期停留。
- 反向组合是强力但限时状态，会消耗蓝条。
- 场景切换不改变人物位置。
- 形态切换也不改变人物位置。
- 好的关卡设计应该让玩家同时思考：现在该换场景，还是该换形态。

## 资源 UI

后续 UI 不再使用简单文字生命，而是改成横版动作游戏常见的资源条：

- **血条 HP**：显示当前生命，受伤减少，归零失败。
- **蓝条 MP**：用于维持反向组合、释放技能、触发高级形态能力。
- **怪物血条 Enemy HP**：怪物被攻击后显示血量变化，方便玩家判断伤害是否命中和剩余血量。

建议表现：

- 血条放左上，红色或金红色。
- 蓝条放血条下方，蓝色或青蓝色。
- 晶石和场景/形态标记放右上或血条旁边。
- 蓝条低于 25% 时闪烁提示，提醒玩家反向组合即将结束。
- 怪物血条显示在怪物头顶，平时可以淡化，受击后短时间高亮。

蓝条基础规则：

- 同属性组合不持续消耗蓝条。
- 反向组合持续消耗蓝条。
- 使用技能消耗蓝条。
- 命中敌人、收集能量碎片、回到同属性组合可以恢复蓝条。

## 推荐操作

参考 4399 横版动作小游戏的键位习惯：

- A/D 或方向键：移动。
- J：攻击。
- K：跳跃，支持二段跳。
- L：切换人物形态，光形态 / 影形态。
- 空格：切换场景，光场景 / 影场景。
- U/I/O 或后续技能键：释放技能，消耗蓝条。
- Shift：冲刺。
- R：重开。
- P：暂停。

说明：

- 空格只负责场景切换。
- L 只负责形态切换。
- J/K 保持攻击和跳跃，不再承担切换功能。
- 技能键后续引入，必须绑定蓝条消耗。

## 当前实现状态

当前原型已经拆成独立的场景与形态状态：

- 空格只切换光/影场景。
- L 只切换光/影形态。
- 人物可以处于“光场景 + 影形态”或“影场景 + 光形态”。
- 近战刀光已改成动态挥砍，并修复了不会消失的问题。
- 目前还没有反向组合时间限制。
- 目前还没有血条/蓝条 UI，仍是文字生命显示。
- 目前怪物仍是简单 HP 小格子，需要升级成更明确的怪物血条。

当前代码拆分方向：

- `sceneMode`：只控制场景、平台、陷阱、晶石、敌人、背景。
- `formMode`：只控制人物外观、移动参数、攻击方式、冲刺参数、形态技能。

## 第一阶段：拆分场景与形态

状态：已完成到当前原型。

### 1. 状态拆分

新增两个独立状态：

```text
sceneMode = "light" 或 "shadow"
formMode = "light" 或 "shadow"
```

原来的 `environment` 不再同时代表场景和形态。

预期效果：

- 空格只改变 `sceneMode`。
- L 只改变 `formMode`。
- 玩家可以在任意场景里使用任意形态。

### 2. 场景切换

空格切换光场景 / 影场景。

光场景：

- 天堂风格背景。
- 云桥、圣光平台、白金遗迹。
- 光场景专属晶石、机关和敌人。

影场景：

- 深渊风格背景。
- 熔岩、尖塔、裂隙平台。
- 影场景专属晶石、机关和敌人。

规则：

- 切换场景时，人物位置不变。
- 只改变外部世界，不改变人物能力。

### 3. 形态切换

L 切换光形态 / 影形态。

光形态：

- 天使外观。
- 跳跃更高。
- 下落更慢。
- 空中控制更稳。
- J 发射远程圣羽。
- 适合探索、保命、远程输出。

影形态：

- 地狱外观。
- 地面速度更快。
- 冲刺更远。
- 下落更重。
- J 使用近战斩击。
- 适合突进、爆发、快速通过危险区。

规则：

- 切换形态时，人物位置不变。
- 只改变人物能力，不改变外部场景。

## 第二阶段：让两个系统产生组合玩法

### 4. 4 种组合的用途

光场景 + 光形态：

- 稳定组合，不持续消耗蓝条。
- 新手最安全的组合。
- 适合跳平台、拿空中晶石、远程打敌人。

光场景 + 影形态：

- 反向组合，持续消耗蓝条。
- 在明亮场景里高速突进。
- 可用近战破坏光场景中的重甲敌人或障碍。
- 蓝条耗尽后自动回到光形态，或强制受到短暂硬直。

影场景 + 光形态：

- 反向组合，持续消耗蓝条。
- 在深渊危险地形中用缓降保命。
- 适合穿越熔岩间隙、远程处理深渊敌人。
- 蓝条耗尽后自动回到影形态，或取消缓降优势。

影场景 + 影形态：

- 稳定组合，不持续消耗蓝条。
- 风险较高但速度最快。
- 适合限时路线、近战爆发、冲刺穿越危险区。

### 5. 反向组合限时

反向组合指：

- 光场景 + 影形态。
- 影场景 + 光形态。

设计原因：

- 反向组合通常更强、更灵活，也更有策略价值。
- 如果没有限制，玩家可能长期停留在最强组合，场景和形态选择会失去意义。
- 加入蓝条消耗后，反向组合变成“关键时刻使用”的战术资源。

规则建议：

- 进入反向组合后开始持续消耗蓝条。
- 蓝条耗尽时，自动切回与当前场景一致的形态。
- 自动切回时不改变人物位置。
- 蓝条低于 25% 时，形态标记闪烁。
- 如果玩家主动切回同属性形态，蓝条停止消耗并开始缓慢恢复。

推荐数值：

- 满蓝条可维持反向组合 6 到 8 秒。
- 使用普通技能额外消耗 15% 到 25% 蓝条。
- 使用大技能额外消耗 40% 到 60% 蓝条。

### 6. 双切换谜题

关卡中可以设计需要同时考虑场景和形态的路线。

例子：

- 先切到光场景，让云桥出现。
- 再切到影形态，用高速冲刺穿过云桥上的机关。
- 或先切到影场景，让裂隙平台出现。
- 再切到光形态，用缓降拿到深渊上方晶石。
- 但由于反向组合限时，玩家需要在蓝条耗尽前完成动作。

预期效果：

- 场景切换解决“路在哪里”。
- 形态切换解决“怎么通过这条路”。
- 蓝条限制解决“什么时候开始行动”。

## 第三阶段：战斗策略

### 7. 攻击表现由“形态 + 场景”共同决定

攻击的基础方式由人物形态决定，但具体表现和附加效果要受当前场景影响。

光形态基础攻击：

- 远程圣羽。
- 适合远距离、安全输出、空中攻击。

影形态基础攻击：

- 近战斩击。
- 适合贴身爆发、击退和破坏障碍。

4 种组合下的攻击表现：

| 当前组合 | 攻击表现 | 玩法差异 |
| --- | --- | --- |
| 光场景 + 光形态 | 圣羽带金白光轨 | 标准远程，弹道稳定，适合新手输出 |
| 影场景 + 光形态 | 圣羽变成冷色净化弹 | 射程略短但更亮，可照出隐藏目标或压制深渊敌人 |
| 光场景 + 影形态 | 近战斩击带金色裂光 | 攻击范围略宽，适合破坏光场景中的护盾或机关 |
| 影场景 + 影形态 | 近战斩击带红黑火痕 | 伤害和击退更强，适合深渊场景中的爆发战斗 |

设计原则：

- 形态决定“远程还是近战”。
- 场景决定“攻击视觉、附加属性、交互对象”。
- 同一个形态在不同场景下不应该只是换颜色，而要有轻微手感差异。
- 后续敌人、机关和隐藏收集可以读取“攻击属性”来判断是否触发。

### 8. 敌人按场景出现，弱点按形态处理

敌人可以由场景决定出现与否：

- 光场景敌人。
- 影场景敌人。
- 双场景通用敌人。

敌人弱点由人物形态处理：

- 怕光形态：远程圣羽克制。
- 怕影形态：近战斩击克制。
- 混合敌人：需要先用一种形态破盾，再换另一种形态输出。

预期效果：

- 场景决定遇到什么敌人。
- 形态决定用什么方式打。

### 9. 怪物血条与受击反馈

怪物被攻击后必须有明确的血条反馈。

显示规则：

- 怪物头顶显示横向小血条。
- 满血时血条可以较淡，避免画面太乱。
- 被击中后血条高亮 1 到 2 秒。
- 血量低于 30% 时血条变成警示色。
- 死亡时血条和怪物一起淡出或爆散。

表现建议：

- 普通怪：短血条，红色填充。
- 精英怪：更长血条，带边框或分段。
- Boss：屏幕顶部大型 Boss 血条。

和攻击系统的关系：

- 光形态远程命中后，血条减少并闪白/金光。
- 影形态近战命中后，血条减少并震动/红光。
- 克制攻击造成更多伤害，血条减少更明显。
- 非克制攻击可以显示较小伤害，避免玩家误以为没打中。

### 10. 技能与蓝条

后续技能系统使用蓝条作为主要资源。

基础技能建议：

光形态技能：

- 短按技能：圣光护盾，短时间减伤。
- 长按技能：蓄力圣羽，发射更强的穿透弹。
- 在影场景中使用时，消耗更多蓝条，但可以照亮隐藏路径或压制深渊敌人。

影形态技能：

- 短按技能：暗影突刺，快速向前突进并造成近战伤害。
- 长按技能：炼狱爆斩，小范围高伤害。
- 在光场景中使用时，消耗更多蓝条，但可以破坏光场景重甲障碍。

技能设计原则：

- 技能不能免费释放，必须消耗蓝条。
- 反向组合中释放技能消耗更高。
- 同属性组合中释放技能更稳定，消耗较低。
- 蓝条管理应成为战斗和跑图的核心判断。

### 11. 形态能量

光形态能量：

- 命中敌人后积累。
- 满能量后圣羽变成三连发或穿透弹。

影形态能量：

- 近战命中后积累。
- 满能量后斩击扩大或附带冲击波。

规则建议：

- 切换形态不会清空能量，但不同形态能量分开计算。
- 这样玩家会在两种形态之间做资源管理。

## 第四阶段：机关与收集

### 12. 场景机关

只受 `sceneMode` 影响：

- 光场景：圣光门、云桥、光柱、电梯平台。
- 影场景：裂核门、熔岩升降台、暗影桥、深渊封印。

这些机关主要决定地图结构。

### 13. 形态机关

只受 `formMode` 影响：

- 光形态：激活圣印、净化污染、照亮隐藏路线。
- 影形态：破坏裂石、撞开重门、吸收暗能量。

这些机关主要决定角色如何互动。

### 14. 隐藏收集

隐藏晶石可以要求双条件：

- 光场景 + 影形态：明亮场景中用地狱冲刺拿到隐藏晶石。
- 影场景 + 光形态：深渊场景中用天使缓降拿到空中晶石。

预期效果：

- 增加探索价值。
- 鼓励玩家尝试 4 种组合。

## 第五阶段：关卡结构升级

### 15. 分段目标

把单一“收集 5 枚晶石到传送门”升级为多段目标：

1. 学会场景切换：通过光/影平台路线。
2. 学会形态切换：用光/影形态解决移动和攻击问题。
3. 学会组合使用：在指定场景中切换正确形态。
4. 激活双界传送门，进入终点。

### 16. 小 Boss 战

Boss 战应同时考验两个系统：

- Boss 改变场景，迫使玩家切换 `sceneMode` 找安全平台。
- Boss 改变护盾，迫使玩家切换 `formMode` 使用正确攻击。
- 光形态负责远程窗口。
- 影形态负责近战爆发窗口。

预期效果：

- Boss 是对“场景切换 + 形态切换”的综合考试。

## 推荐实现顺序

1. 拆分 `sceneMode` 和 `formMode`。
2. 改键位：空格切场景，L 切形态。
3. 让背景、平台、陷阱、晶石、敌人只看 `sceneMode`。
4. 让角色外观、移动、攻击、冲刺只看 `formMode`。
5. 增加 4 种组合的 HUD 标记。
6. 把文字生命改成血条 HP。
7. 增加蓝条 MP。
8. 把怪物 HP 小格子升级为怪物血条。
9. 增加怪物受击高亮、血条闪烁和低血量警示。
10. 增加反向组合持续消耗蓝条。
11. 蓝条耗尽时自动回到同属性形态。
12. 为 4 种组合补齐攻击表现和附加效果。
13. 引入第一批技能，并接入蓝条消耗。
14. 设计第一段双切换限时路线。
15. 增加场景机关和形态机关。
16. 增加敌人弱点和形态能量。
17. 增加小 Boss。

## 下一步建议

下一步不要先做复杂技能，而是先做资源系统。

最小可落地版本：

- 把生命文字改成血条。
- 增加蓝条。
- 把怪物 HP 小格子改成头顶血条。
- 怪物被攻击后血条高亮，低血量变色。
- 反向组合持续消耗蓝条。
- 蓝条耗尽后自动切回当前场景对应的同属性形态。
- 场景切换和形态切换仍然不改变人物位置。

完成这一步后，再引入技能。这样技能系统会有明确成本，不会变成无脑释放。
