# 六道轮回 · 装备系统

正式游戏已接入首版符文掉落、库存、阴阳十二槽、战斗效果与装备存档。当前可用效果以游戏内 `E` 装备页为准；完整 144 条复杂机制目录保留为设计目标，部分道位采用简化实现，可命名配装预设和训练木桩等仍待完善。

## 使用与查看

- [正式游戏](../index.html)：按 `E` 打开双面六边形装备盘；中央太极翻面，选择道位与符文，放入草案后确认装备。`L` 切阴阳配装，空格独立切换天庭与地府。
- [独立设计试装](../runes-preview.html)：查看完整提案效果和三个示范配装，预览库存与存档独立于正式游戏。
- [系统设计](reincarnation-runes-design.md)：六道用途、阴阳切换、掉落、存档、组合限制与完整目标。
- [十二生肖效果目录](reincarnation-runes-catalog.md)：设计目标中的 24 种主武器与 144 条道位效果。
- [结构化效果数据](reincarnation-runes-catalog.json)：与目录对应的设计数据，描述文字不是可执行技能配置。

六道依次为阿修罗道（武器）、天道（术法）、人间道（身法）、畜生道（灵契）、饿鬼道（续航）、地狱道（附效）。同一生肖可放在不同道位；每面同种生肖最多一枚，两面同时装备同种生肖需要两枚。

正式 Boss 击败后立即发放对应符文，最多持有两枚，之后每次转为 10 符墨。符墨目前仅累计，无消费功能。已确认配装和库存保存在 `liangyi-runes-v1`，旧通关记录各补一枚对应符文；演武临时提供每种两枚，退出恢复正式配装，不发放永久奖励。存储失败会在装备页提示。

正式战斗中可以暂停编辑草案，到安全处再确认；关闭后草案仅在本次页面会话中保留。演武允许试装并立即确认。应用配装不恢复生命、灵力或冷却。更完整的操作、存档规则和验证方法见[游戏说明](../README.md)。

## 发布与维护

站点使用静态文件发布，无需构建。完整发布 `shadow-jump/`，确保 `src/rune-store.js`、`src/rune-combat.js`、`src/rune-ui.js` 与 `rune-ui.css` 随主页面发布。正式装备入口位于游戏顶部、暂停页和章节选择面板。`runes-preview.html` 继续作为独立设计页面使用。

正式效果维护在 `src/rune-combat.js`；装备说明由同一模块的 `getEntry` 生成，应与实际执行规则保持一致。修改完整目标设计时，同步更新设计 Markdown、JSON 和独立预览页的内联目录，不能仅修改设计描述就视为游戏已支持。交互目标见系统设计第 7 节。

部署后检查正式掉落、翻面、草案确认、同侧移位、卸下、刷新恢复、演武存档隔离，以及窄屏下的六槽与操作按钮。
