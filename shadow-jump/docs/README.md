# 六道轮回 · 装备系统设计

当前阶段：交互设计预览。正式游戏尚未接入符文掉落、库存、战斗效果和装备存档。

## 查看方案

- [六边形双面轮回盘试装](../runes-preview.html)：中央太极翻面，点选道位，预览并确认装备。
- [系统设计](reincarnation-runes-design.md)：六道用途、阴阳切换、掉落、存档、组合限制和接入计划。
- [十二生肖效果目录](reincarnation-runes-catalog.md)：24 种主武器与 144 条道位效果。
- [结构化效果数据](reincarnation-runes-catalog.json)：与目录对应的设计数据，描述文字不是可执行技能配置。

六道依次为阿修罗道（武器）、天道（术法）、人间道（身法）、畜生道（灵契）、饿鬼道（续航）、地狱道（附效）。同一生肖可放在不同道位；每面同种生肖最多一枚，两面同时装备同种生肖需要两枚。

## 发布与维护

站点使用静态文件发布，无需构建。`runes-preview.html` 是完整导出的独立页面，运行资源随页内置，预览配装通过浏览器本地存储保存，与游戏存档独立。游戏顶部“试装”和章节选择面板均有入口。

修改效果时同步更新 Markdown、JSON 和预览页的内联目录；修改交互时同步更新系统设计第 7 节。部署后检查翻面、预览确认、同侧移位、卸下、刷新恢复，以及窄屏下的六槽与操作按钮。
