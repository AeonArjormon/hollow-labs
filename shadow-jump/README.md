# 两仪行 · 十二元辰

一个基于 Phaser 的国风横版平台动作小游戏。玩家化身汉服巡界使，往返天庭与地府，以御剑和镇魂两种术法寻找通路，收集每章的 5 枚元辰灵印，挑战十二生肖元辰，重整两界星序。项目目录沿用 `shadow-jump`。

御剑形态采用青玉白衣、玉簪长发与长剑，擅长远攻、跳跃和缓降；镇魂形态采用玄衣朱绶与赤金剑芒，擅长近身斩击、快速移动和突进。沿途生灵包括云中纸鹤傀、提灯阴差、持盾天兵与冥火狐妖。

## 本地运行

在仓库根目录运行静态文件服务器：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

在浏览器打开 `http://127.0.0.1:8000/shadow-jump/`。项目无需构建或安装 npm 依赖；Phaser 4.2.0 随项目放在 `vendor/` 目录中，由当前站点加载，无需访问第三方 CDN。下载完整仓库后，可通过本地服务器离线运行；首次访问 GitHub Pages 仍需要网络。

部署时请一并发布 `vendor/`、`src/` 和 `assets/` 目录。如果提示游戏引擎文件未能加载，请检查 `vendor/phaser.min.js` 是否已发布，并在 GitHub Pages 部署完成后刷新页面。

独立图鉴位于 `http://127.0.0.1:8000/shadow-jump/art-preview.html`，可比较双形态主角的实机尺寸与放大细节，切换待机、奔跑、起跳、下落、攻击、冲刺、受伤、换形八种动作，并查看四类小怪和十二生肖动态立绘。图鉴支持暂停动画细看，与游戏共用绘制代码。

## 操作

| 操作 | 键位 |
| --- | --- |
| 左右移动 | `A` / `D` 或左右方向键 |
| 跳跃，空中可再跳一次 | `K`，轻点低跳、按住高跳 |
| 攻击 | `J`，支持持续按住 |
| 形态技能 | `U` |
| 切换所在世界 | 空格 |
| 切换角色形态 | `L` |
| 沿当前朝向冲刺 | `Shift` |
| 暂停或继续 | `P` 或 `Esc` |
| 关闭操作指南 | `Esc` |
| 从头重新开始 | `R` |

触屏使用下方的方向、跳跃、攻击、技能与切换按钮；横屏可获得更大的游戏画面。顶部按钮也可以切换世界和形态、查看指南、开关声音和调低动态效果。

所在世界决定可落脚的平台、可见灵印和敌人，形态决定移动与攻击能力。御剑使用飞剑远攻，技能“玉清护体”提供护盾并发射贯虹飞剑；镇魂使用近身剑斩，技能“镇魂突袭”扩大斩击，并在冲刺可用时向前突进。天庭御剑、地府镇魂时恢复灵力，交错施术时持续消耗灵力；耗尽后自动切回与所在世界相配的形态。

## 十二元辰与章节

顶部元辰星盘可直接选择任意章节。每章需要集齐 5 枚灵印、击败当值元辰，再进入右侧两界门，才会记录正式通关。Boss 的半血觉醒会改变招式和受击弱点，按 `L` 切换御剑飞剑或镇魂剑斩应对。

| --- | --- | --- | --- |
| 子鼠 · 掌灯使 | 子夜渡口 | 地府 | 锁魂符 → 散灵扇 |
| 丑牛 · 镇岳君 | 镇岳天门 | 天庭 | 冲阵 → 符雨 |
| 寅虎 · 破军将 | 伏虎幽谷 | 地府 | 飞扑 → 散灵扇 |
| 卯兔 · 望舒仙 | 月桂仙台 | 天庭 | 符雨 → 锁魂符 |
| 辰龙 · 沧溟帝 | 沧溟龙渊 | 地府 | 回旋灵流 → 符雨 |
| 巳蛇 · 青绫仙 | 青绫仙苑 | 天庭 | 散灵扇 → 回旋灵流 |
| 午马 · 烈曜君 | 赤焰古道 | 地府 | 冲阵 → 散灵扇 |

| 亥猪 · 玄坛尊 | 归元玄坛 | 天庭 | 冲阵 → 回旋灵流 |

六类招式均有出招预警：锁魂符瞄准蓄力时的位置；散灵扇发射扇形飞符；冲阵横穿元辰坛；符雨落在三处地面标记；飞扑跃向标记位置并在落地后产生双向冲击；回旋灵流向四周释放灵弹。根据标记移步、起跳或寻找弹幕空隙。

当前十二章共用一套基本路线，采用三种平台高度节奏，并按章节变化初始世界、平台与灵印所在世界、小怪血量和巡逻速度。各章配置自己的生肖形象、名称、数值及两阶段招式组合。Boss 战场为两界共用的连续地面。

“演武 · 直面元辰”会直接进入当前章的 Boss 战场，免去沿途灵印收集和小怪。演武通过后可返回本章历练；演武结果不计入正式通关和十二元辰归位记录。

## 检查点与保存

落地经过长明灯检查点会保存本次复活位置，首次激活恢复部分生命和全部灵力。死亡后可从已点亮的长明灯继续，保留本次收集的灵印、角色成长及战斗进度。`R`、“重新出发”或选择章节会重新开始对应关卡，重置本次探索状态。

正式通关后，已归位的生肖编号保存在当前浏览器、当前站点的 `localStorage` 中，键名为 `liangyi-zodiac-progress-v1`；刷新后可在星盘查看，并再次挑战任意章节。本局位置、生命、灵印和检查点状态只保留在当前运行中，刷新页面会从第一章重新开始。声音与动态效果偏好另存于 `shadow-jump-preferences`。

切换浏览器、端口或站点地址会使用对应的本地存储；清除站点数据会清除这些记录。本地存储不可用时，通关记录仅在当前页面会话中保留。

## 源码与验证

- `src/game-scene.js`：输入、物理、战斗、关卡进度和界面联动。
- `src/data/zodiac.js`：十二生肖的名称、章节、初始世界、生命、招式、预警和背景文案。
- `src/data/level-01.js`：基本路线、灵印、敌人、检查点，以及生成十二章变体的配置函数。
- `src/art.js`、`src/enemy-art.js`、`src/zodiac-art.js`、`src/world-art.js`：汉服主角、四类小怪、十二生肖与两界场景的绘制和动画，详见 [美术说明](assets/README.md)。
- `art-preview.html`：独立的两界生灵图鉴。
- `index.html`、`styles.css`：菜单、HUD、操作指南与触控布局。
- `vendor/`：随站点托管的 Phaser 引擎与许可证。

在仓库根目录使用 Node.js 18 或更高版本运行逻辑回归测试：

```sh
node --test shadow-jump/tests/*.test.cjs
```

逻辑回归测试覆盖跳跃容错、冲刺、暂停、投射物寿命、检查点、重开及切换世界后的碰撞处理，以及启动依赖缺失时的提示和重新加载操作。测试使用模拟场景，渲染、音效、触控多指操作和完整路线可玩性仍需浏览器验证。

浏览器验收可按以下步骤进行；此清单是验证方法，不表示十二章完整流程均已逐一实测：

1. 打开图鉴，切换八种动作并暂停，检查双形态主角、四类小怪及十二生肖的绘制、动画和裁切。
2. 从第一章开始，验证轻重跳、二段跳、冲刺、两界平台切换、灵力恢复与耗尽，并沿路线收齐 5 枚灵印。
3. 点亮长明灯后死亡续关，确认灵印和战斗进度保留；重新出发后确认本次状态重置。
4. 用星盘依次进入十二位元辰的演武，检查六类招式的预警、半血换招、弱点切换及战斗中的暂停与恢复；演武通过后确认归位数量不增加。
5. 在正式历练中完成“灵印齐全、击败 Boss、进入界门”流程，检查下一章入口、星盘归位标记和刷新后的本地记录。
6. 分别检查三种高度路线与天庭、地府初始章的前进和回访路径，再使用窄屏和触屏检查按钮可达性、多指移动与跳跃、指南焦点及暂停恢复。
