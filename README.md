# Hollow Labs // 空洞实验室

一些好玩的交互小工具和实验性小游戏。每个项目都是独立的单页面，无需安装，打开即用。

## 目录结构

```
hollow-labs/
├── index.html              ← 首页入口
├── bangbu/
│   └── index.html          ← 邦布语翻译器
└── shadow-jump/
    ├── index.html          ← Shadow Jump 游戏
    └── 玩法优化计划.md      ← 游戏设计文档
```

## 项目

### 工具 (Tools)

| 项目 | 说明 |
|------|------|
| [邦布语翻译器](https://aeonarjormon.github.io/hollow-labs/bangbu/index.html) | 把任意文字翻译成绝区零的邦布语（2-bit 映射编码） |

### 实验 (Experiments)

| 项目 | 说明 |
|------|------|
