# Hollow Labs // 空洞实验室

一些好玩的交互小工具和实验性小游戏。每个项目都是独立的单页面，无需安装，打开即用。

## 目录结构

```
hollow-labs/
├── index.html              ← 首页入口
├── bangbu/
│   └── index.html          ← 邦布语翻译器
└── liangyi/
    ├── index.html          ← 两仪行 · 十二元辰 游戏
    └── 玩法优化计划.md      ← 游戏设计文档
```
