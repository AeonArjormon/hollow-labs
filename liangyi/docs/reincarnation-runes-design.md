# 六道轮回 · 十二生肖符文系统

> 《两仪行 · 十二元辰》完整装备设计目标，2026-11-17。正式游戏已接入首版 Boss 掉落、阴阳十二槽、战斗效果与装备存档，当前效果以游戏内 `E` 装备页为准。本文与完整 144 条目录包含后续复杂机制、视觉和交互目标，不是已实现功能清单；数值不代表已完成平衡验证。当前使用说明见 [README](README.md)。

## 1. 核心体验

**生肖决定特性，六道决定用途，阴阳决定战法。**

每位生肖 Boss 掉落对应的生肖符文。玩家将符文装进六道轮回盘，每一道都有阳槽、阴槽，共十二槽。按 `L` 切换整套阴阳配装，当前一侧的六槽共同构成武器、术法、身法、灵契、续航和附效。

例如：阳面用兔符的回旋月轮铺上蛇符的侵蚀，再切阴面，用蛇符的钩镰结算侵蚀；或者阳面用牛符盾枪防反积攒灵力，阴面换猪符重刃抓住 Boss 收招打一记重击。

十二种符文、两种极性、六种用途，形成 **144 个明确的槽位效果**。这是效果目录的数量，不是 144 件互相独立的武器，也不等于 144 种最终流派。真正的组合来自六槽配合和两套配装的切换。

## 2. 十二槽的职责

所有生肖都能放入任何一道。六道有固定职责，防止多枚符文同时覆盖普攻、争夺按键。

| 道位 | 阳槽 / 阴槽负责什么 | 对应操作 | 未装备时 |
| --- | --- | --- | --- |
| 阿修罗道 · 兵 | 主武器、攻击距离、动作节奏、连段和蓄力方式 | `J` 普攻 | 阳面基础飞剑；阴面基础剑斩 |
| 天道 · 术 | 一项主动术法，具有自己的灵耗和冷却 | `U` 术法 | 阳面玉清护体；阴面镇魂突袭 |
| 人间道 · 行 | 冲刺、二段跳、空中控制等身法变式 | `Shift`、`K` | 完整基础冲刺、轻重跳和二段跳 |
| 畜生道 · 契 | 一只主灵兽或一种伴随灵体 | 自动跟随，随玩家行为行动 | 无伴随物 |
| 饿鬼道 · 息 | 灵力获取、返还、储存或有条件的续航 | 命中、精准闪避、防反等已有行为 | 基础自然恢复 |
| 地狱道 · 劫 | 按条件给直接攻击附加侵蚀、破势、追猎、连锁等效果 | 按各效果的命中条件触发 | 无额外附效 |

**只有阿修罗道改变主武器。** 在天道装龙符会得到龙系术法，但不会把正在使用的兔月轮换成长枪。界面同时显示道名和“武器 / 技能 / 身法”等白话标签，不要求玩家先记住六道含义。

### 阴阳与天庭、地府的关系

- `L` 切配装：武器、技能、身法和伴随物随之变化。当前侧六槽生效，另一侧待命。
- 空格切世界：改变平台、敌人可见性和场景，沿用现有规则。
- 阳面可以近战，阴面也可以远程。阳偏向主动建立机会，阴偏向改变节奏和兑现机会；这是风格方向，不强制所有符文采用同一种连招。
- 保留青玉白衣与玄衣朱绶两套人物辨识。主手武器、持握动作、背饰和攻击轨迹随配装变化。
- 取消异界持续扣蓝后强制换形的规则，否则玩家无法长期使用自己喜欢的配装。首轮建议所有组合自然恢复 4 灵力/秒，同界额外恢复 2 灵力/秒；自然恢复上限 8/秒。世界与配装匹配是小奖励，不是配装使用限制。
- 初始灵力上限建议 100。零灵力仍能普攻、跳跃、冲刺、换界和切阴阳；付费强化与术法需有足够灵力。
- 原有“飞剑弱点 / 剑斩弱点”已改为“阳性弱点 / 阴性弱点”，攻击距离与极性分别记录。首版对应弱点极性造成完整伤害，非弱点极性造成 45% 伤害，半血时切换弱点；后续可考虑让弱点增加破势效率。

### 输入与动作

沿用现有按键，不新增六个技能键。普通武器按住 `J` 自动连攻；蓄力武器按下 `J` 起手、按住蓄力、松手释放，短按也能打出基础攻击。武器说明必须标出这两类操作。

有回收或折返的武器，用两次离散按键完成第二阶段；按住连攻会按其默认节奏自动完成，不要求额外按键。触屏攻击按钮同样区分按下、保持、松开，支持按住蓄力和再次点按回收；移出按钮或系统取消触摸时取消蓄力，不误发重击。冲刺能够取消蓄力和允许取消的收招，但不会提前触发松手重击，也不返还已支付的强化灵力。切形缓冲至攻击允许取消的时刻，不提供无代价取消所有重武器后摇的捷径。

盾枪等防反武器在连段起手的**新一次 `J` 按下**提供短暂前方格挡窗口，建议 0.12 秒、成功触发间隔至少 1 秒。持续按住自动连攻不重复开启此窗口。红色不可格挡攻击只能闪避。精准闪避使用 `Shift`：冲刺无敌段实际躲过原本会命中的攻击才算成功，每次冲刺最多记一次。这样猪符等资源符文可以支持盾枪，也能支持其他武器。

## 4. 同一枚符文怎样换出六种用途

以辰龙符为例，下表简述效果目录中的十二项能力；完整触发条件和限制见目录：

| 放置道位 | 阳面玩法 | 阴面玩法 |
| --- | --- | --- |
| 阿修罗 · 武器 | 盘龙长枪：直刺连攻，末段向另外最多两名敌人导雷 | 云龙软鞭：弧形扫鞭，末段轻拉小怪并放出雾雷 |
| 天道 · 技能 | 九霄雷阵：30 灵力布阵 3 秒，首雷为直接命中，冷却 10 秒 | 玄云归涡：30 灵力布雾涡 2.5 秒，牵引小怪后雾爆，冷却 12 秒 |
| 人间 · 身法 | 踏云行：空中冲刺后缓降 0.35 秒，触地且 5 秒冷却结束才恢复 | 云隐错步：地面冲刺留下 0.6 秒雾影诱导小怪，间隔 5 秒 |
| 畜生 · 灵契 | 青霆幼龙：直接命中后向另一目标吐雷，间隔 3 秒 | 玄雾盘龙：拦下一发普通弹幕，消耗后 8 秒恢复 |
| 饿鬼 · 续航 | 聚雷归息：一次直接攻击命中至少两名敌人回 6 灵力，间隔 1.5 秒 | 云息回流：精准闪避储存 6 秒云息，下次付费施术返 6 灵力，获取间隔 2 秒 |
| 地狱 · 附效 | 雷脉连引：普攻终结向另外最多两名敌人导雷，间隔 1 秒 | 雾印凝雷：直接命中每秒最多叠一层雾印，三层时消耗并产生雾雷 |

把龙符从阳修罗移到阳地狱，主武器会恢复基础飞剑，但其他武器的连段终结也能带导雷。若想同时持龙枪并用龙符导雷，这个单侧配装不允许重复装备龙符；可保留龙枪自带的终结导雷，把地狱槽让给蛇、虎等其他特性。

**属性变化随用途出现。** 武器槽调整单击倍率、攻速、射程和破势；术法槽调整灵耗、冷却与覆盖；身法槽调整地空机动；灵契槽提供有限协击或防护；续航槽改变灵力经济；附效槽改变异常与控制。不要给所有位置统一套“攻击 +10%”。

首轮可以用一组有代价的武器参数验证差异：重武器单击约为标准斩的 1.6 倍，但完整动作约为 1.7 倍；轻武器单击约 0.65 倍，完整动作约 0.7 倍。优势来自破势、位移和命中机会，不是纸面攻速越快越好。上述只是调试比例，需连同实际命中率、距离和收招一起验证。

## 5. 三套完整的双面配装

以下每列都是六枚互不重复的符文；跨面重复需要第二枚。设计预览和演武可临时试装全部符文，正式历练只使用已持有的数量。这些是示范配装，不是强制套装，也没有“集齐指定六件额外 +50%”之类的隐藏优势。

### 月轮蚀魂：铺伤 → 走位回收 → 切面收割

| 道位 | 阳面 | 阴面 |
| --- | --- | --- |
| 阿修罗 · 兵 | 兔：回旋月轮 | 蛇：钩镰结算侵蚀 |
| 天道 · 术 | 羊 | 鸡 |
| 人间 · 行 | 马 | 兔 |
| 畜生 · 契 | 犬 | 猴 |
| 饿鬼 · 息 | 鼠：首次命中新目标回灵 | 猪 |
| 地狱 · 劫 | 蛇：直接攻击施加侵蚀 | 虎 |

阳面先投月轮，调整站位让回程继续命中；蛇附效使敌人带上侵蚀，鼠续航鼓励覆盖新目标。看到 Boss 收招后切阴，用蛇钩镰提前结算侵蚀，再借兔身法离开危险范围。

月轮去、回的多次命中不会重复刷回灵；侵蚀被结算的部分立即扣除。弱点是铺伤需要时间，对经常离场、净化状态的敌人效率较低。未获得第二枚兔、蛇时，用基础武器或其他已持有的符文补缺，不影响基础通关。

### 踏云雷骑：冲阵 → 空中变向 → 远程压线

| 道位 | 阳面 | 阴面 |
| --- | --- | --- |
| 阿修罗 · 兵 | 马：移动突刺 | 鸡：直线羽弩 |
| 天道 · 术 | 牛 | 兔 |
| 人间 · 行 | 猴：有冷却的空中踏步 | 马 |
| 畜生 · 契 | 犬 | 羊 |
| 饿鬼 · 息 | 鼠 | 猪 |
| 地狱 · 劫 | 龙：终结导雷 | 蛇 |

阳面利用骑枪向前打开通路，以猴身法在空中冲刺调整落点；末段导雷处理附近敌人。拉开距离后切阴，用羽弩穿透一线追兵，月影术辅助控制距离。

龙链雷必须寻找另一名敌人，不能在单体 Boss 身上来回弹；空中踏步需要触地和冷却同时满足才恢复。优势是机动和清群，代价是需要管理位置，对单体要抓准出手时机。

### 镇岳归元：精准防反 → 储灵 → 重刃破势

| 道位 | 阳面 | 阴面 |
| --- | --- | --- |
| 阿修罗 · 兵 | 牛：盾枪防反 | 猪：蓄力重刃 |
| 天道 · 术 | 羊：护愿区域 | 龙 |
| 人间 · 行 | 兔 | 马 |
| 畜生 · 契 | 犬 | 猴 |
| 饿鬼 · 息 | 猪：精准防反 / 闪避回灵 | 鼠 |
| 地狱 · 劫 | 虎 | 蛇 |

阳面以盾枪读招防反，猪续航奖励成功应对攻击，羊术法提供有限保护。Boss 进入明显收招或破势时切阴，将灵力投入重刃强化；随后利用身法脱离，回到阳面重新寻找机会。

没有“挨打越多回血越多”的循环。防反有方向与时机限制，红色攻击不能格挡；重刃打空会浪费窗口，技能与重击也争用同一条灵力。

## 6. 掉落、数量与成长

1. **正式历练击败 Boss，必得一枚对应生肖符文。** 获得时立即写入持久存档，不必再进出口；之后死亡或刷新不追回。章节通关仍按灵印齐全、击败 Boss、走入界门记录，奖励与通关分开保存。
2. 同一侧每种生肖最多一枚；阴阳两侧各装同一生肖，需要持有两枚。符文没有先天阴阳属性，位置决定其阴阳效果，拆装不销毁。
3. 单种符文最多保留两枚用于装备。第三次及之后正式胜利，显示对应符文掉落再自动转为“符墨”。符墨用于外观、配装命名装饰等后续横向内容，不加入首版战力升星。
4. 不做随机掉率、随机品质和随机词条。同一生肖的效果可预测，玩家能按想玩的武器主动选择对应 Boss。
5. 开局开放十二个槽位，空槽有基础能力；进度来自获得更多玩法，不靠锁槽拖时间。当前星盘可直接选章的习惯保留。
6. 演武不产生永久符文或符墨，但提供“演武试装”使用全部符文。退出演武恢复正式配装，不把试装物品写入背包。
7. 每次正式关卡实例中的 Boss 奖励只发一次。死亡续关不得重建已领取 Boss 奖励；重新出发或重进章节建立新实例，可正常重刷。奖励、数量和本实例领取标记一起提交，避免刷新重复结算。
8. 旧存档迁移：现有已通关生肖各补发一枚符文，记录迁移版本；已迁移的存档不再次发放。新存档数据损坏时保留原值备份，不以空存档静默覆盖。

第一次获得符文时，掉落面板只突出“阳武器 / 阴武器”和一个建议用途，其他六道详情按需展开。新玩家第一次可以直接用主武器感受变化，后续再学续航与附效的组合。

## 7. 交互与视觉

### 轮回盘与编辑

装备页采用**六边形双面轮回盘，正面为阳、背面为阴，每面六槽**。正式游戏已接入双面盘、库存、草案编辑和安全确认；本节继续保留完整交互目标，人物预览、可命名预设和训练木桩等尚未接入。六道沿六个角排列：顶端为兵，随后顺时针依次为术、行、契、息、劫。翻到另一面后，同一道仍在相同的视觉位置，名字与图标保持正向，方便对照两侧配装。

点击中心太极翻转轮回盘，再选择当前面的槽位装备。中心同时标出当前“阳面 / 阴面”和“翻至阴面 / 翻至阳面”，不只靠颜色辨认。翻面保留两侧已装备内容、配装草案和已选道位，详情切到新一面的对应槽；翻面本身不确认候选符文，也不改变实际战斗形态。隐藏背面不可点击、不可通过 `Tab` 聚焦，也不向辅助技术重复读出。

宽屏在六边形旁显示人物、当前面武器预览和槽位详情；窄屏仍保留完整六边形，将人物预览、效果比较与装备操作放到盘面下方。各槽标签可分行，触摸区域至少 44 × 44 像素；确认按钮保持可见或可正常滚动到达，不覆盖槽位与详情。

键鼠、触屏都以“点击中心翻到目标面 → 点槽位 → 点符文 → 查看变化 → 确认装备”为完整流程；已在目标面时直接选槽。选符文先展示候选效果，在允许换装的场景点击“确认装备”才应用该槽变化；战斗暂停仍只编辑草案，遵守下文的应用限制。取消预览保留原装备。已被同侧其他槽占用的符文显示占用位置，提供“移动到此槽”的明确动作；不默默复制，也不自动拆走另一侧的唯一一枚。拖拽可作为额外快捷方式，所有操作均可通过点击完成。

键盘可用 `Tab` 依次访问中心翻面按钮、当前面六槽及详情操作，以 `Enter` 或空格激活，并显示清晰焦点。六槽顺序固定为兵、术、行、契、息、劫；中心翻面后焦点保留在中心，选中道位保留。关闭槽位详情后焦点回到对应槽位，面板操作不传给游戏。触屏单击即能选槽与翻面，不依赖悬停、长按或拖动才能查看说明。

普通模式使用短暂的立体翻转呈现正反面；翻转期间暂不接受槽位操作，完成后只开放新一面，避免点到背面。减少动态模式直接切换两面或使用短淡入淡出，保留道位位置、选中状态和焦点，不要求观看旋转动画才能操作。

预览先显示行为变化，例如“飞剑 → 回旋月轮”“按住连攻 → 松手放蓄力箭”；再显示实际受影响的射程、攻速、移速、灵耗等数据。不用一个无法解释的“战力”数字代表所有武器好坏。

换装免费。开局准备、已激活长明灯附近且无敌对战斗时、章节结算中可以确认换装。战斗中可暂停查看和编辑草案，但确认按钮说明“到安全处应用”。未来切换预设也遵守同一规则。当前正式界面关闭后保留本次页面会话的草案，点击“还原草案”才丢弃修改；刷新后只恢复已确认的正式配装。

提供三个可命名的配装预设和训练木桩；演武可试所有符文。预设缺符文时指出缺哪一枚，允许检查方案，不以非法库存直接进入正式关卡。换装确认不加生命、不回灵、不重置冷却；检查点自身的首次补给单独结算。

### 战斗可读性

- HUD 只突出当前主武器、`U` 术法冷却、灵力，以及另一侧即将切出的武器。完整十二槽信息留给可翻转的装备盘，每次呈现当前面的六槽。
- 战斗中按 `L` 切面时，HUD 的太极印翻转，人物换持姿、主武器与术法图标同步切换；文字短暂显示“阳 · 望舒月轮 / 阴 · 蜕影钩镰”。无额外无敌帧，建议切换间隔 0.6 秒。
- 符文图形采用地支篆印与生肖轮廓，阳用玉金流纹、阴用朱墨刻痕；符文结构和名字也区分阴阳，不能只靠颜色。
- 24 种武器需要各自剪影、持握姿态、起手、命中停顿、收招、轨迹和音色。重锤有重心下压，弓有拉弦，链刃有回收，月轮有往返；不能只换人物手里的小图标。
- 灵契与附效做减法：一只主灵契，残影和协击灵体是短暂特效。自己的粒子淡于敌方危险预警；低动态模式降低粒子密度、抖动和屏闪，不删除必要的落点预警。
- 身法改动不得让玩家穿墙、越过未开放的边界或把世界切换后的落点放进实体平台。所有基础路线能以空槽配装通过，装备只提供更舒适的路线与战斗选择。

## 8. 组合边界与首轮调试规则

下列规则先作为共同基础，再调各符文强弱。不要同时叠加生肖套装、五行克制、槽位邻接、品质升星等第二套配装谜题。

| 情况 | 共同规则 / 建议起点 |
| --- | --- |
| 切阴阳 | 生命、灵力共享；不触发补给。两侧术法分别记冷却，离场仍计时。切回不刷新，也不取消已承诺的收招 |
| 冲刺与身法 | 基础冲刺冷却跨侧共享；各身法额外能力有自己的冷却。额外空中次数跨侧共享，触地且冷却结束才刷新 |
| 已出手攻击 | 记录出手时武器、极性、伤害和地狱附效，飞行中切面不改它的属性。命中回灵只在攻击来源侧仍为当前侧、对应资源符文仍装备时结算；旧侧飞行物既不触发旧侧已停用的饿鬼效果，也不套用新侧效果 |
| 旧侧效果 | 已施加给敌人的持续伤害、标记自然到期；已支付的定时术法持续至到期，同一施法来源只保留一个。常驻增益和主灵契随旧侧停用，旧灵契不继续发射攻击 |
| 待兑现回灵 | 切面清除旧侧待兑现的回灵条件，保留触发冷却，切回不能找回待兑现奖励。已支付术法本身仍按原时长结束，敌人已挂标记与持续伤害按原规则自然到期 |
| 召唤与切面 | 主灵契最多一只；切换不补满其拦截次数或立即刷新协击。同一灵契的充能 / 冷却保留 |
| 直接命中附效 | 术法直接命中能否触发地狱效果，以术法与地狱条目各自的触发标注为准。只接受 J 普攻、连段终结或其他特定条件的效果，不能由 U 命中自动替代触发 |
| 衍生伤害 | 链雷、残影、召唤、持续伤害、侵蚀结算不能再次启动完整附伤与回灵链。目录中明确消耗标记的效果仅读取并消耗状态 |
| 一次攻击 | 同一次挥刀、同一发月轮的往返、同一批扇羽使用同一个攻击编号；每个资源效果最多结算一次，再遵守自身间隔 |
| 首次新目标 | 按当前战斗内的敌人实例记录；切面、换槽、脱离再贴近不能刷新。Boss 阶段变化仍是同一目标 |
| 资源触发 | 同一道资源效果跨两侧共享触发间隔，建议至少 0.75 秒；直接命中回复还受全局 10 灵力/秒上限约束，逐帧检查不能发多次奖励 |
| 侵蚀 | 持续伤害共用一个可视状态，最多 3 层，建议每层 4 秒；刷新层数不重复兑现旧伤害。蛇镰最多提前结算剩余伤害的 50%，等量扣除状态中的待结算伤害 |
| 破势与控制 | 普通敌人可推、拉、挑；Boss 使用破势条与短暂硬直，免疫强拉、挑飞、强制传送。破势结束后建议有 3 秒控制保护，避免永久连控 |
| 多弹与导雷 | 一批飞羽对单体有总伤害上限；导雷最多额外 2 个目标，同一条链不返回已命中的目标；没有其他目标时不转换为额外单体倍伤 |
| 属性叠加 | 同类百分比加算。攻速增益上限 +30%，移速增益 +20%，冷却缩减上限 25%，持续减伤上限 35%；具体能力的瞬间防反与闪避另按时机判定 |
| 护盾与治疗 | 总护盾上限为最大生命的 25%；同源覆盖取更高值而非叠加，持续时间不超来源上限。常驻灵契不得免费治疗；若后续加治疗，必须消耗资源或有战斗次数限制 |
| 属性上限切换 | 首版符文不增减生命 / 灵力上限，避免切盘回血。若未来开放，保持缺失量且钳制范围，不能通过反复切换产生资源 |
| 符文替换 | 技能冷却按角色 + 生肖 + 极性 + 道位保留。更换新技能时，取新技能自身剩余冷却与该槽剩余冷却的较大值；恢复能力不得因拆装再次领取开场充能 |

不会为“凑齐六生肖”直接发伤害奖励。值得追求的是月轮覆盖侵蚀、盾枪为重刃储灵、位移把敌人排成一线等玩家能观察和操作的组合。

## 9. 当前接入与后续完善

首版已经打通正式装备与战斗，完整目录的复杂机制仍需逐项完善。当前实现边界如下，不以设计目录的条目数量作为完成度。

- `src/rune-store.js` 管理库存、配装、正式 Boss 奖励与保存；`src/rune-combat.js` 执行武器、术法及其余道位效果；`src/rune-ui.js` 与 `rune-ui.css` 实现正式六边形双面装备盘，由 `src/game-scene.js` 联动。
- 阴阳配装映射 `light / shadow`，世界 `sceneMode` 独立。`L` 切面，空格切世界，`E` 打开装备页。基础自然回灵为每秒 4 点，同界额外每秒 2 点；不再异界持续扣灵或零灵力强制切面。
- 十二生肖在两面六道均提供首版可用效果，说明由战斗模块生成。部分身法暂以移动参数变化实现，灵契以随行协击实现；完整目录中的专属拦截、诱导等行为不能据此视为已完成。Boss 对弱点极性承受完整伤害，对非弱点极性承受 45% 伤害，半血时切换弱点。伤害按攻击出手时保存的极性结算，随后切面不会改变该次攻击的极性。
- 正式游戏采用“选槽 → 选符文 → 放入草案 → 确认装备”，确认一次应用两面完整配装。正式战斗中可编辑草案，安全处再应用；演武临时提供每种两枚，并与正式库存和配装隔离。可命名预设、训练木桩及完整人物装备预览仍是后续工作。
- 持久存档键名为 `liangyi-runes-v1`，保存持有数量、符墨、两侧槽位、迁移及奖励记录；没有保存命名预设。原章节通关键独立保留。正式击败 Boss 即保存奖励，第三枚起每次转为 10 符墨；符墨目前仅累计，无消费入口。存档失败提示本次仅会话有效，损坏数据先备份再重建。
- 美术与战斗仍需按各武器的剪影、动作、节奏和反馈验收，不能以“24 个武器名称已填表”代替完整战法和美术完成度。
- JSON 效果目录是设计资料，包含人类可读描述和标签，不直接执行。当前以正式装备页说明与运行代码为准；后续逐项补齐复杂机制时同步维护对应设计与实现。
- GitHub Pages 继续用静态资源；新符文图片、音效与代码随仓库发布，沿用本地 Phaser 引擎，不引入必需的第三方在线依赖。

## 10. 实现后的验收标准

1. 同一枚符文移动到不同道，变的是对应功能；非修罗道不能意外覆盖主武器。十二生肖、阴阳、六道共 144 条配置均有说明或明确未开放状态。
2. 无符文能完整过基础路线；阳面近战与阴面远程都能击破相应极性弱点。零灵力不锁死操作。
3. 一枚符文不能同时占两个槽；两枚可分配到阴阳各一处。同侧重复、非法库存、缺符文预设都得到可理解的反馈。
4. 正式击杀必掉，演武不写库存；领取后死亡、刷新保留，连点结算不多发；重复 Boss 按新的正式挑战实例结算。
5. 月轮往返、扇羽多弹、链雷、残影、灵契、持续伤害不会触发无限资源或伤害递归。Boss 不被无限控制。
6. 切形、换世界、换装、载入预设不能补血、补蓝、清冷却、重复召唤充能或无限空中跳跃。
7. 三套示范配装各有可复现的战斗循环；对单体、密集群体、两侧夹击、移动目标分别有优势与短板。调数值前先确认动作、落点和受击反馈成立。
8. 键盘和触屏都能完成选槽、比较、装备、移除、切预设、取消与确认；暂停输入不会泄漏到游戏。窄屏不遮住确认按钮。
9. 两侧 24 种主武器的剪影、动作、节奏和命中反馈可辨识；满配装时，Boss 的攻击预警仍是画面中最清楚的信息。
